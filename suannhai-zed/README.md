# Themes
### Formosa

- Suannhai Jiufen (Dark)
- Suannhai Lam-ni (Dark)
- Suannhai Hue-poo (Light)

### Nippon

- Suannhai Rouiro (Dark)
- Suannhai Sumi (Dark)
- Suannhai Koiai (Dark)
- Suannhai Torinoko (Light)
- Suannhai Shironeri (Light)

# Installation

1. Open the **Command Palette** with <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>
2. Open the **Extensions** view with the `zed: extensions` command
3. Search for `Suannhai`
4. Click on **Install**
5. Open the **Command Palette** again
6. Open the **Theme selector** with the `theme selector: toggle` command
7. Search for `Suannhai` and choose a variant
