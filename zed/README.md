# Suannhai for Zed

8 color themes drawn from traditional Formosa (Taiwan) and Nippon (Japan) palettes -- 5 darks and 3 lights, each with its own accent set for keywords, functions, types, and strings. Nippon colors sourced from [nipponcolors.com](https://nipponcolors.com). Full syntax coverage for TypeScript, Python, C#, C++, Rust, and more.

## Install

1. Open Zed
2. Open the command palette (`Cmd+Shift+P`) and enter `zed: extensions`
3. Search for "Suannhai" and install
4. Open the command palette and enter `theme selector: toggle`, then select a variant

## Color Sources

- **Formosa** palettes use original colors named in Tai-lo romanization
- **Nippon** palettes use traditional Japanese colors from [nipponcolors.com](https://nipponcolors.com)
